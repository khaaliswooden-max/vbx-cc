# How to Use Me — VBX Command Center (Offline Dashboard)

**You received two files:**

1. **`VBX_Command_Center_Dashboard_offline.html`** — this dashboard (the viewer)
2. **`VBX_Command_Center_v1.xlsx`** — the data workbook

The dashboard is just the *viewer*. It shows whatever data workbook you load into it.

---

## Open it (30 seconds)

1. **Double-click** `VBX_Command_Center_Dashboard_offline.html`. It opens in your web browser.
2. Click the gold **`UPLOAD WORKBOOK →`** button (top-right).
3. Select the **`VBX_Command_Center_v1.xlsx`** file.
4. The numbers appear. Done.

✅ **No internet required.** &nbsp; ✅ **Nothing to install.** &nbsp; ✅ **Works on Windows and Mac** (Chrome, Edge, Safari, or Firefox).

> Tip: keep both files in the same folder so they're easy to find together.

---

## Using the dashboard

- **As-of date** (top-right): change it to see the numbers as of any date — great for "where were we last month?"
- **Click any KPI card** (e.g. *Revenue Booked YTD*, *Active Pipeline*) to drill into the underlying detail.
- **Scenario Mode** (lower section): drag the win-rate / booking sliders to model projected Year-1 P/L.
- **BD Cadence** table: the little bar charts are 13-week trends — one bar per week.

---

## Getting updated numbers

The dashboard never changes the data — it only reads it. To see fresher numbers, ask for an updated **`VBX_Command_Center_v1.xlsx`** and upload it the same way. The dashboard file itself doesn't need to be replaced.

---

## Please keep it internal

Once you load the workbook, this view contains confidential Visionblox business information — pipeline, revenue, partners. **Keep both files internal.** Do not post them to public websites, file-sharing links, or anywhere outside approved Visionblox channels.

---

## If something looks off

- **Blank / all zeros?** Make sure you clicked *Upload Workbook* and selected the `.xlsx` file.
- **Looks unstyled?** Try opening in **Chrome** or **Edge**.
- **Still stuck?** Contact the sender (Enterprise Capture & Compliance).
